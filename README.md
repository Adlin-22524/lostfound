# Digital Lost & Found Portal

A simple website project built for academic viva demonstration using Jenkins CI/CD pipeline.

---

## 🚀 Features
- User Signup & Login (frontend demo)
- Report Lost Items with photo upload & preview
- View Found Items with search & filter
- Admin Dashboard to update item status
- Dark Mode toggle for better UI
- Simple frontend demo (HTML, CSS, JS)

## 🔧 CI/CD Pipeline
- Code hosted on **GitHub**
- **Jenkins pipeline** automates build & deployment
- Deployed on **Vercel** for live demo
- Every commit → auto build → auto deploy → live URL updated

---

## 🎯 Outcome
This project demonstrates a practical **DevOps CI/CD workflow** with a lightweight web application, suitable for viva presentation.  
Judges can see:
- Authentication system (login/signup flow)  
- Item reporting & admin approval  
- Automated deployment pipeline
